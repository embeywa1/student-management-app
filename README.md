# Student Management System (SMS) Dashboard

A production-grade, single-page Graphical User Interface (GUI) application built entirely using **JavaFX**. This system is architected to provide institutional administrators with a centralized control engine to handle student life cycles, tracking records, academic course units, and real-time grade assignments.

---

## 🚀 Features

* **Dynamic Registry Operations:** Add, modify, and view student profiles with strict input-validation checks that prevent duplicate registration keys.
* **Modular Course Enrollment Matrix:** Filter candidate eligibility dynamically. The system isolates and displays only students who haven't yet been registered for a selected unit.
* **Centralized Grade Ledger:** Streamline grade inputs. Administrators select a student, pull up only their active courses, and instantly update scores with live, visual rendering updates.
* **Modern Single-Page Dashboard:** A high-contrast slate-styled sidebar (`#2c3e50`) switches views instantly using a `StackPane` rendering engine, eliminating the need for cluttered pop-up window management.

## 🛠️ Step-by-Step Setup Guide

Follow these sequential instructions to install dependencies, compile, and run the application on your local development workstation.

### Step 1: Install the Java Development Kit (JDK)
The application requires **JDK 11 or higher** (JDK 17 or 21 Long-Term Support versions are highly recommended). 
#### **Linux (Ubuntu/Debian/Kali)**
Open your terminal console and execute:
Bash
sudo apt update
sudo apt install default-jdk -y


If you do not have a JDK installed on your operating system, follow the instructions for your platform below:
macOS
If you use Homebrew, run:

Bash
brew install openjdk
Alternatively, download the macOS installer package from Azul Zulu JDK or Eclipse Temurin.

Windows
Download the x64 Installer executable binary from Eclipse Temurin Releases.

Run the .exe wizard installer and ensure you check the box that says "Add to PATH" during setup.

Verification Check: Open a fresh terminal or command prompt window and run javac -version. It should output your active Java version number.

Step 2: Download the JavaFX SDK
Modern versions of Java do not bundle GUI modules inside the core JDK runtime. You need to supply the platform-specific library binaries separately.

Navigate to the official OpenJFX download mirror: Gluon JavaFX Downloads.

Select your Operating System and download the JavaFX SDK package matching your architecture (e.g., x64 or aarch64).

Unpack/Unzip the downloaded directory and place it into a structured location on your system.

Example Local Path Structure: ~/.javafx/javafx-sdk-21.0.2/lib/ or C:\javafx-sdk\lib\

💻 Compiling and Running the Code
Navigate to the local repository folder containing your StudentManagementApp.java source file and execute the terminal commands relevant to your operating system.

On Linux and macOS Platforms
Ensure you update the /path/to/ string with the absolute path pointing to your local JavaFX SDK folder.

1. Compile the Bytecode:

Bash
javac --module-path ~/.javafx/javafx-sdk-21.0.2/lib --add-modules javafx.controls StudentManagementApp.java
2. Execute the Application Engine:

Bash
java --module-path ~/.javafx/javafx-sdk-21.0.2/lib --add-modules javafx.controls --enable-native-access=javafx.graphics StudentManagementApp
On Windows Command Prompt (CMD)
Ensure you point the library string to your localized SDK deployment path.

1. Compile the Bytecode:

DOS
javac --module-path "C:\javafx-sdk\lib" --add-modules javafx.controls StudentManagementApp.java
2. Execute the Application Engine:

DOS
java --module-path "C:\javafx-sdk\lib" --add-modules javafx.controls --enable-native-access=javafx.graphics StudentManagementApp

🛑 Common Troubleshooting Matrix
Error: "Could not find or load main class..."

Fix: Ensure you are executing the java launch command from the exact folder where your compiled .class binaries sit. If you modified the code to include a package declaration line (package com.sms;), you must compile with the flag -d . and launch using the qualified identifier handle: com.sms.StudentManagementApp.

Error: "GraphicsDevice initialization failed"

Fix: This happens primarily on Linux systems if you attempt to launch the application from an elevated root shell environment (sudo). Always run the application as your standard desktop user account.

Warning: "A restricted method in java.lang.System has been called..."

Fix: This is a harmless developer diagnostic alert generated by modern JVM versions. Appending the --enable-native-access=javafx.graphics flag completely silences this terminal logging constraint.
